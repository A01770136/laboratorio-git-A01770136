# Mi resumen de comandos Git

git status: Me muestra cómo está mi repositorio y si tengo archivos modificados o pendientes.

git add: Prepara un archivo para incluirlo en el siguiente commit.

git commit: Guarda los cambios preparados en el historial de Git.

git push: Sube mis commits al repositorio de GitHub.

git pull: Descarga los cambios más recientes que otras personas hayan subido.

git log: Me muestra el historial de commits del repositorio.

git diff: Me enseña los cambios que hice pero que todavía no he preparado con git add.

git restore: Sirve para descartar un cambio o recuperar un archivo como estaba en el último commit.

git restore --staged: Saca un archivo de la zona de preparación sin borrar los cambios que hice.
